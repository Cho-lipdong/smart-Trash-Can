# 스마트 쓰레기통

쓰레기 적재량을 실시간으로 측정하고 알려주는 스마트 쓰레기통

## 문제

기존에 사용하는 쓰레기통은 내부 쓰레기의 적재량을 직접 뚜껑을 열어서 확인해야 하기에 불필요한 뚜껑 개폐로 인한 문제점을 확인하였다.

## 사용 부품 및 기술

- ESP32
- 초음파 센서(HC-SR04)
- LED

## 시스템 구성

입력(센서) → 판단(코드) → 출력(동작) → 표시(화면/웹)

> 블록도 이미지를 여기에 넣으세요. 손그림 사진도 괜찮습니다.

## 실행 방법

1. 부품을 배선표대로 연결합니다.
2. 코드를 보드에 업로드합니다.
3. 전원을 연결하면 화면에 측정값이 표시됩니다.
